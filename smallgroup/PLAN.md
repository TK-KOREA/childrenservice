# 어린이소그룹 앱 기획

행사마다 페이지를 새로 만들지 않고, 앱 하나에 행사를 계속 쌓는다.
주소: https://tk-korea.github.io/childrenservice/smallgroup/ (배포 후)

## 화면

| 화면 | 내용 |
|---|---|
| 홈 `#/` | **다가오는 행사 1개를 맨 위에 큰 카드로** (D-day, 날짜·장소, "안내 보고 참석 회신하기"). 그 뒤 행사가 있으면 "이어서 있을 행사". **지난 행사는 맨 아래 접힌 목록**으로. 날짜가 지나면 자동으로 내려간다. |
| 행사 `#/e/<id>` | 한눈에 → 일정(타임라인) → 비용 → 준비물(체크) → 꼭 알아 주세요 → 저녁 식사(식당 1곳, 정하기 전엔 "정하는 중") → 참석 회신 → 참석 현황(저녁 인원 합계 포함). 위쪽 바로가기 칩, 아래 고정 "참석 회신하기", 공유 버튼(카톡 공유/링크 복사). |

회신 항목: 가정이름, 참석 여부, 어른/아이/유아 수, 저녁 함께 여부, 남길 말.
같은 가정이름으로 다시 보내면 덮어쓴다(대부도와 같은 방식).

## 기술 구조

- **앱**: GitHub Pages 정적 PWA. 100-verses처럼 빌드 없는 바닐라 JS 모듈 + manifest + service worker(네트워크 우선, 현장 오프라인 대비). 다크 모드 지원.
- **행사 내용**: `events/<id>.json` (일정·요금·식당 등). 목록은 `events/index.json`.
- **회신 저장**: 구글 시트 + Apps Script 웹 앱(JSON API). 행사마다 시트 탭 하나(`20261017_seoulgrandpark` 등).
  - `GET ?action=status&event=<id>` → 회신 목록
  - `POST {action:'rsvp', event, ...}` → 저장 후 회신 목록
- `js/config.js`의 `API_URL`이 비어 있으면 **미리보기 모드**(이 기기에만 저장, 예시 데이터 표시).

3. `setup` 실행 → `20261017_seoulgrandpark`, `20261004_daebudo` 탭 생성.
4. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → `/exec` 주소 복사.

대부도 회신 기록은 예전 시트에 그대로 있다. 새 시트로 옮기고 싶으면 `20261004_daebudo` 탭에 열 순서를 맞춰 붙여 넣는다.

## 새 행사 추가 (매번)

1. `events/20261017_seoulgrandpark.json`을 복사해 `events/<날짜_이름>.json` 만들고 내용 고치기. 필요 없는 섹션(fees, restaurants 등)은 지우면 화면에서도 빠진다.
2. `events/index.json`에 한 줄 추가.
3. `Code.gs`의 `EVENTS`에 id 추가 → `setup` 실행 → 배포 관리에서 새 버전.
4. 푸시 후 단톡방에 `…/smallgroup/#/e/<id>` 공유.

## 디자인 (2026-10-15 개편: "한 장")

행사 화면 첫 화면에 스크롤 없이 **요점 네 줄(모임·비용·저녁·챙길 것) + 함께 가는 가정 얼굴 + 회신 버튼 하나**만 둔다. 회신은 아래에서 올라오는 시트(dialog)로 받고, 보낸 뒤에는 초록 줄 "우리 가정 · N명 · 고치기"로 바뀐다. 일정·비용·준비물·저녁·공지·현황은 그 아래 "자세히"로.
- 요점 줄: 행사 JSON의 `summary`(k·v·sub, `map`이면 지도 링크, `to`면 그 구역으로 이동). 저녁 줄은 `dinner`에서 자동으로 만든다(식당 이름을 넣으면 저절로 바뀜).
- 당일에는 맨 위에 **지금 · 다음 두 가지** 카드가 뜬다(일정 시각 기준, 30초마다). `?now=2026-10-17T14:40`을 주소에 붙이면 그 시각으로 미리 볼 수 있다.
- 시스템 글꼴 하나, 단풍 주황 하나. 예전 입장권(`ticket`, `passes`, `overview`) 필드는 더 쓰지 않는다.
- 다음 단계 후보: 도착 확인(체크인), 회신에 카풀 칸, 질문 남기기.

## 확인이 필요한 것

- 동물원 안 동선(동물관 이름)은 예시다. 당일 현장 지도 보고 조정.
- 운송패키지 요금은 받은 캡처 기준(어른 14,500 / 청소년 9,000 / 어린이 8,000 / 유아 6,200).
- 공유 링크 미리보기(카톡)는 행사별이 아니라 앱 공통 제목으로 보인다. 행사별 미리보기가 꼭 필요하면 행사마다 작은 이동용 html을 두는 방법이 있다.
